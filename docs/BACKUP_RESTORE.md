# Backup / Restore

## Status

**PLANNED / NOT IMPLEMENTED IN R3.0.**

Archive is not backup. Local durable sync state is not backup. Supabase canonical data is not automatically equivalent to a user-portable backup artifact.

Portable backup, restore validation, and legacy-data migration are later governed R3 chapters. R3.0 performs no destructive conversion and no restoration automation.

Until those chapters are implemented, maintainers must not claim portable restore capability from this repository.
